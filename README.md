# Giro Certo Veículos

## O que o JavaScript faz
- Monta o menu e o rodapé de todas as páginas (escritos uma vez só no `script.js`)
- Estoque: filtro por categoria, busca pelo nome, preço máximo e ordenação, tudo ao vivo
- Simulador de financiamento (entrada e prazo, juros fictícios de 1,9% ao mês)
- Contato: valida o formulário e guarda a mensagem no navegador (localStorage)
- Menu que abre e fecha no celular

## Arquivos
- `index.html`, `estoque.html`, `sobre.html`, `contato.html`: as páginas
- `script.js`: lista de carros e todo o comportamento
- `style.css`: visual (cores no topo, em `:root`)

## Para mexer
- Adicionar ou tirar carro: edite a lista `carros` no começo do `script.js`
- Taxa do financiamento: `JUROS_MES`
